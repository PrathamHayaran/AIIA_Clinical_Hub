# AIIA Clinical Trial Hub - Frontend Application

Modern, enterprise-grade React client for the **All India Institute of Ayurveda (AIIA)** Clinical Trial Management System (CTMS).

## Technology Stack
- **Framework**: React 18 + Vite (SPA)
- **Styling**: Tailwind CSS + Glassmorphism tokens + Dark/Light mode theme system
- **Routing**: React Router v6 (Role-guarded routes)
- **State & Real-time**: React Context + Axios Interceptors + Socket.IO-Client
- **Visuals & Charts**: Recharts + Lucide React + Framer Motion animations
- **Typography**: Outfit & Inter fonts

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local Vite development server (Port 5173)
npm run dev

# 3. Production build validation
npm run build
```
